# Security reports

Use [GitHub private vulnerability reporting](https://github.com/AdhamAfis/AutomataViz/security/advisories/new) for security findings. Do not publish exploit details, credentials, or private data in an issue.

Include the affected commit or release, environment, reproduction steps, impact, and any proposed fix. Remove real personal data from examples. There is no guaranteed response or patch timeline.

The project is under development. Prefer the latest available code when reproducing an issue; older snapshots do not have a promised maintenance window. The website's development download is not a stable release.
