# Educational project website research

Reviewed 23 October 2026. Primary project sites only.

- [BlueJ](https://bluej.org/): identifies its beginner audience immediately, places download/install directly after its introduction, and groups documentation and teaching resources separately. Desktop layout inspected in a browser.
- [Greenfoot](https://www.greenfoot.org/door): introduces the learning purpose alongside an actual software screenshot and separates software access from educator resources. Desktop layout inspected in a browser.
- [PhET](https://phet.colorado.edu/): organizes access to simulations and teaching activities as primary tasks. Homepage content reviewed.
- [JFLAP](https://www.jflap.org/whatis.html): describes its automata teaching scope in terms of creating, converting, and experimenting with representations. Indexed official content reviewed; direct homepage/tutorial fetches returned 403, so its current visual design was not used as evidence.

## Applied to AutomataViz

Use a compact project introduction next to real screenshots; bring installation near the top; organize capabilities around learning topics; give learners concrete exercises; preserve a separate explanation of regex equivalence and its limits. Use a restrained document layout and native controls, not cinematic effects.

Do not imitate university affiliations, testimonials, research validation, platform-specific installers, communities, or resource collections that this project does not have. One bundled JAR remains the actual download.
